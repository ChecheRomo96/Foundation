Detailed Description

template<typename T>
class Foundation::Containers::CircularBuffer< T >

Fixed-capacity FIFO with circular storage reuse.

Template Parameters
TStored value type.

CircularBuffer operates on a caller-provided array and never allocates. The array is not owned and must outlive the buffer.

Parameters

sizeMaximum number of values that may be stored.
Note
A null pointer with zero capacity is a valid empty buffer. A null pointer with non-zero capacity creates an invalid but safe buffer for which Push() and Pop() return false.
