Detailed Description

template<typename T>
class Foundation::Math::BasicRatio< T >

Exact rational value backed by a supported 32-bit integer.

Template Parameters
Tint32_t for signed ratios or uint32_t for unsigned ratios.

A zero denominator is the only invalid BasicRatio state. A zero numerator remains a valid mathematical ratio. Invalid conversion returns zero, and reduction canonicalizes an invalid ratio to 0 / 1.
