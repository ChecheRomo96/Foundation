Detailed Description

template<typename TickType = Foundation::Time::Tick32>
class Foundation::Scheduling::BasicTask< TickType >

Interface implemented by cooperatively scheduled tasks.

Template Parameters
TickTypeTick specialization shared by the scheduling family.

BasicTaskScheduler calls ShouldRun() and Run() synchronously. Derived objects are not owned by the scheduler.
