Manual acceptance checklist for every native desktop preset and configuration.

Run this checklist from a clean clone or a worktree containing exactly the release candidate. A preset identifies the target toolchain and architecture; Debug and Release are configurations inside that one preset. Both libraries belong in build/<preset>/artifacts/lib for development and testing, while the exported dist/<preset> package contains Release only.

Feature-Set Matrix

Debug and Release are not enough by themselves because module options change the installed headers, compile definitions, and binary. Run the default set on all four desktop presets. Run the expanded option matrix on at least windows_msvc_x64 and macos_arm64; run one non-default set on each secondary compiler preset to prove that arguments are forwarded correctly. Every row must pass Debug and Release build/tests followed by a fresh Release export.

If disabling one module breaks another module, record the failure as a CMake dependency-model defect rather than silently changing the checklist. The build must either support that combination or reject it at configure time with a precise dependency message.

Checklist for Each Preset

  • Record the commit SHA and confirm the worktree contains the intended changes.
  • Record CMake, Ninja or Visual Studio, and compiler versions.
  • Remove build/<preset> and dist/<preset> through clean.
  • Configure the preset once with the fresh option.
  • Confirm CMAKE_CONFIGURATION_TYPES contains Debug and Release.
  • Build the Foundation target in Debug.
  • Build the Foundation target in Release without reconfiguring.
  • Confirm the two archives have distinct names and the expected architecture.
  • Run one export command; export has no configuration override.
  • Confirm that export installed Release and did not install Debug.
  • Confirm public headers and all CMake package metadata were installed.
  • If examples are enabled, confirm only Release executables and launchers exist in bin/examples; record them as examples, never as tests.
  • Confirm only the Release imported location exists in the package.
  • Build a separate consumer with find_package(Foundation CONFIG REQUIRED) and Foundation::Foundation in Release.
  • Run registered native tests in both configurations.
  • Confirm the default feature set discovers and passes every expected GoogleTest case; do not use AllowNoTests for release evidence.
  • Repeat one fresh export with a module disabled and verify its metadata.
  • Restore and re-export the preset defaults before retaining release artifacts.

Windows Commands

Run MSVC from a Visual Studio Developer PowerShell. Set $Preset to windows_msvc_x64, then repeat with windows_clang_x64 after confirming that clang and clang++ resolve to the intended installation.

$Preset = "windows_msvc_x64"
git rev-parse HEAD
cmake --version
cmake --list-presets=all
Get-Command cl
Get-Command ninja -ErrorAction SilentlyContinue
./scripts/clean.ps1 $Preset -Dist
./scripts/configure.ps1 $Preset -Fresh
Select-String -Path "build/$Preset/CMakeCache.txt" `
-Pattern "CMAKE_CONFIGURATION_TYPES"
./scripts/build.ps1 $Preset -Configuration Debug -Target Foundation
./scripts/build.ps1 $Preset -Configuration Release -Target Foundation
Test-Path "build/$Preset/artifacts/lib/Foundation_d.lib"
Test-Path "build/$Preset/artifacts/lib/Foundation.lib"
./scripts/test.ps1 $Preset -Configuration Debug
./scripts/test.ps1 $Preset -Configuration Release
./scripts/export.ps1 $Preset -Fresh
./scripts/test-package.ps1 $Preset -SkipExport
Test-Path "dist/$Preset/include"
Test-Path "dist/$Preset/lib/Foundation.lib"
Test-Path "dist/$Preset/lib/cmake/Foundation/FoundationConfig.cmake"
Test-Path "dist/$Preset/lib/cmake/Foundation/FoundationTargets-release.cmake"
if (Test-Path "dist/$Preset/lib/Foundation_d.lib") { throw "Debug archive was packaged" }
if (Test-Path "dist/$Preset/lib/cmake/Foundation/FoundationTargets-debug.cmake") {
throw "Debug import metadata was packaged"
}
Select-String -Path "dist/$Preset/lib/cmake/Foundation/FoundationTargets-release.cmake" `
-Pattern "IMPORTED_LOCATION_RELEASE.*Foundation.lib"

Every displayed Test-Path must print True, neither absence check may throw, and the Select-String archive check must return a match. Use dumpbin /headers for MSVC or llvm-readobj for Clang when recording the archive machine type.

Validate cache overrides independently; then restore the default package:

./scripts/export.ps1 $Preset -Fresh `
-CMakeArguments "-DFOUNDATION_SCHEDULING=OFF"
Select-String `
-Path "dist/$Preset/lib/cmake/Foundation/FoundationBuildInfo.cmake" `
-Pattern 'Foundation_FEATURE_SCHEDULING "OFF"'
./scripts/export.ps1 $Preset -Fresh

macOS Commands

Set PRESET to macos_arm64, then repeat the complete checklist with macos_x64.

PRESET=macos_arm64
git rev-parse HEAD
xcode-select -p
xcrun clang++ --version
cmake --version
ninja --version
cmake --list-presets=all
./scripts/clean.sh "$PRESET" --dist
./scripts/configure.sh "$PRESET" --fresh
grep "CMAKE_CONFIGURATION_TYPES" "build/$PRESET/CMakeCache.txt"
./scripts/build.sh "$PRESET" --config Debug --target Foundation
./scripts/build.sh "$PRESET" --config Release --target Foundation
test -f "build/$PRESET/artifacts/lib/libFoundation_d.a"
test -f "build/$PRESET/artifacts/lib/libFoundation.a"
lipo -archs "build/$PRESET/artifacts/lib/libFoundation_d.a"
lipo -archs "build/$PRESET/artifacts/lib/libFoundation.a"
./scripts/test.sh "$PRESET" --config Debug
./scripts/test.sh "$PRESET" --config Release
./scripts/export.sh "$PRESET" --fresh
./scripts/test-package.sh "$PRESET" --skip-export
test -d "dist/$PRESET/include"
test -f "dist/$PRESET/lib/libFoundation.a"
test ! -e "dist/$PRESET/lib/libFoundation_d.a"
test -f "dist/$PRESET/lib/cmake/Foundation/FoundationConfig.cmake"
test ! -e \
"dist/$PRESET/lib/cmake/Foundation/FoundationTargets-debug.cmake"
grep "IMPORTED_LOCATION_RELEASE.*libFoundation.a" \
"dist/$PRESET/lib/cmake/Foundation/FoundationTargets-release.cmake"
lipo -archs "dist/$PRESET/lib/libFoundation.a"

Both architecture commands must report arm64 for macos_arm64 and x86_64 for macos_x64. Validate an option override, then restore defaults:

./scripts/export.sh "$PRESET" --fresh -- -DFOUNDATION_SCHEDULING=OFF
grep 'Foundation_FEATURE_SCHEDULING "OFF"' \
"dist/$PRESET/lib/cmake/Foundation/FoundationBuildInfo.cmake"
./scripts/export.sh "$PRESET" --fresh
