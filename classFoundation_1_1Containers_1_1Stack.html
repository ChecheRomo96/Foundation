Detailed Description

template<typename T>
class Foundation::Containers::Stack< T >

Fixed-capacity LIFO stack backed by caller-provided storage.

Template Parameters
TStored value type.

Stack never allocates and does not own its storage array.

Creates an empty stack over existing storage.

Parameters
bufferArray containing at least capacity constructed elements.
capacityMaximum number of values that may be stored.
Note
A null pointer with zero capacity is a valid empty stack. A null pointer with non-zero capacity creates an invalid but safe stack for which Push() and Pop() return false.
