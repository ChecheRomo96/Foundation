Matrix types and algorithms.

The Matrix module provides both fixed-size and dynamic matrix implementations together with common matrix algorithms.

Matrix support is intended for:

  • Embedded systems.
  • Digital signal processing.
  • Robotics.
  • Control systems.
  • Numerical methods.
  • Machine learning applications.

Overview

Two matrix storage models are provided:

  • FixedMatrix
  • DynamicMatrix

FixedMatrix stores its data directly inside the object and is intended for applications where matrix dimensions are known at compile time.

DynamicMatrix allocates storage at runtime and is intended for applications where matrix dimensions are not known until execution.

Matrix Types

Fixed Matrices

Fixed-size matrices use compile-time dimensions:

FixedMatrix<float, 3, 3> matrix;

Advantages:

  • No heap allocation.
  • Deterministic memory usage.
  • Compile-time dimension checking.

See:

  • FixedMatrix

Dynamic Matrices

Dynamic matrices determine their dimensions at runtime:

DynamicMatrix<float> matrix;
matrix.Allocate(3, 3);

Advantages:

  • Flexible dimensions.
  • Runtime resizing.

See:

  • Foundation_DynamicMatrix

Operations

Matrix algorithms are provided separately from the matrix containers.

Supported operations currently include:

  • Matrix multiplication.
  • Fixed × Fixed multiplication.
  • Dynamic × Dynamic multiplication.
  • Fixed × Dynamic multiplication.
  • Dynamic × Fixed multiplication.

See:

  • Matrix Operations

Usage Examples

Fixed-size multiplication:

FixedMatrix<float, 2, 2> A;
FixedMatrix<float, 2, 2> B;
FixedMatrix<float, 2, 2> C;
Multiply(A, B, C);

Dynamic multiplication:

DynamicMatrix<float> A;
DynamicMatrix<float> B;
DynamicMatrix<float> C;
Multiply(A, B, C);

Applications

Common applications include:

  • Coordinate transformations.
  • State-space control systems.
  • Robotics kinematics.
  • DSP filter structures.
  • Linear algebra algorithms.
  • Neural networks.
