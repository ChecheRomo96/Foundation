Detailed Description

Matrix types and algorithms.

The Matrix module provides both fixed-size and dynamic matrix implementations together with common matrix algorithms. The entire family is enabled by FOUNDATION_MATH_MATRIX; applications select the storage model when declaring each matrix.

Matrix support is intended for:

  • Embedded systems.
  • Digital signal processing.
  • Robotics.
  • Control systems.
  • Numerical methods.
  • Machine learning applications.

Overview

Two matrix storage models are provided:

  • Fixed
  • Dynamic

Fixed stores its data directly inside the object and is intended for applications where matrix dimensions are known at compile time.

Dynamic allocates storage at runtime and is intended for applications where matrix dimensions are not known until execution.

Matrix Types

Fixed Matrices

Fixed-size matrices use compile-time dimensions:

Dynamic Matrices

Dynamic matrices determine their dimensions at runtime:

Foundation::Math::Matrix::Dynamic<float> matrix;
if (!matrix.Allocate(3, 3)) {
// Invalid dimensions or insufficient memory.
}
Foundation::Math::Matrix::Dynamic
Matrix whose dimensions and storage are selected at runtime.

Advantages:

  • Flexible dimensions.
  • Runtime resizing.
  • Owned heap storage or attached caller-owned storage.
  • Non-throwing allocation-failure reporting.

Operations

Matrix algorithms are provided separately from the matrix containers.

Supported operations currently include:

  • Matrix multiplication.
  • Fixed × Fixed multiplication.
  • Dynamic × Dynamic multiplication.
  • Fixed × Dynamic multiplication.
  • Dynamic × Fixed multiplication.

  • Matrix Operations

Applications

Common applications include:

  • Coordinate transformations.
  • State-space control systems.
  • Robotics kinematics.
  • DSP filter structures.
  • Linear algebra algorithms.
  • Neural networks.
