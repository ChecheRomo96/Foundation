Detailed Description

Static-memory containers for embedded systems.

Containers provides bounded FIFO and LIFO data structures backed by storage supplied by the caller. The module performs no heap allocation and keeps its memory requirements explicit, which makes it suitable for embedded and deterministic applications.

Basic Usage

#include <Foundation_Containers.h>
int storage[4] = {};
Foundation::Containers::Queue<int> queue(storage, 4);
queue.Push(10);
queue.Push(20);
int next = 0;
if (queue.Pop(next)) {
// next == 10
}

Storage and Lifetime Contract

  • A container does not own, allocate, resize, or release its backing array.
  • A null pointer with zero capacity is a valid empty container. IsFull() returns true and insertion fails because no element can fit.
  • A null pointer with non-zero capacity is invalid. IsValid() reports false, Push() and Pop() return false, and no pointer is dereferenced.
  • Non-null storage must remain valid for the complete lifetime of the container.
  • The caller must provide at least capacity constructed T objects because insertion uses assignment into existing array elements.
  • Push(const T&) requires copy assignment; Push(T&&) and Pop() require move assignment compatible with Foundation::Utils::Move.
  • Reset() clears logical state but does not destroy or overwrite elements.
  • Operations are not synchronized; external synchronization is required when one container is shared across execution contexts.
Warning
The container can validate a null pointer/capacity combination, but it cannot determine the actual length or lifetime of a non-null array. The caller remains responsible for providing at least the declared capacity.
