Detailed Description

Build, integration, export, and distribution guide for Foundation.

The Build Guide documents the supported workflows for using Foundation as:

  • an Arduino-compatible source library,
  • a CMake development project,
  • a precompiled static library,
  • a platform-specific embedded dependency.
