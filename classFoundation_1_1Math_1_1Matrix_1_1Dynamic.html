◆ Allocate()

template<typename T>
bool Foundation::Math::Matrix::Dynamic< T >::Allocate ( unsigned int rows,
unsigned int cols )

Ensures valid storage with the requested dimensions.

Existing storage, including attached storage, is reused when its dimensions already match. Otherwise a new owning buffer is allocated. Invalid dimensions, size overflow, or allocation failure return false and leave the matrix unchanged.

◆ Attach()

template<typename T>
bool Foundation::Math::Matrix::Dynamic< T >::Attach ( unsigned int rows,
unsigned int cols,
T * externalData )

Attaches caller-owned storage without allocating.

The caller retains ownership and must keep the buffer alive. Invalid dimensions, a null pointer, size overflow, or an attempt to reattach the matrix's own allocation return false and leave the matrix unchanged.
