Detailed Description

Low-level move, swap, and utility helpers.

Utils provides the small operations needed by Foundation containers without requiring <utility>. The complete v1 public surface consists of Move and Swap; empty historical placeholders were removed before the API freeze.

Definition Swap.h:16

Move performs an rvalue cast; it does not move data by itself. The selected constructor or assignment operator defines the resulting transfer and the valid state of the moved-from object. Swap requires move construction and move assignment compatible with the supplied type. Move itself is constexpr and noexcept; Swap does not promise noexcept because the selected type's move operations may throw.

Runnable Example

Foundation_Utils_MoveAndSwap demonstrates swapping integers and moving a non-copyable object. See Examples for build and launch instructions.
