Detailed Description

template<typename TickType = Tick32>
class Foundation::Time::BasicClock< TickType >

Callback-backed tick source with an associated Frequency.

Template Parameters
TickTypeTick specialization returned by this clock.

Clock does not own external state used by the tick callback. TimePoints returned by Now() and At() retain this Clock's address as their identity, so the Clock must outlive those TimePoints. Copy and move operations are disabled to keep that identity stable.
