Collaboration diagram for Arduino:

Foundation is designed to remain Arduino-compatible without modifying the repository structure.

Arduino requires:

library.properties
src/
examples/

Other directories such as docs, cmake, tests, scripts, and build support files are ignored by the Arduino IDE.

Source Mode

Arduino should normally use Foundation in source mode.

Example:

#include <Foundation.h>

or:

#include <Foundation/Math/Ratio.h>

Macros

Foundation modules may be selected using macros before includes.

Example:

#define FOUNDATION_FULL_BUILD
#include <Foundation.h>

Precompiled Arduino Libraries

Precompiled Arduino libraries are possible, but they are not universal.

They must be separated by architecture and core, for example:

arduino_avr_atmega328p_release
arduino_samd_cortex_m0plus_release
arduino_esp32_xtensa_release

Source mode is recommended for Arduino unless a very specific target is known.
