Matrix arithmetic algorithms.

This module provides algorithms operating on matrix types such as FixedMatrix and DynamicMatrix.

Currently supported operations include:

  • Matrix multiplication.
  • Fixed-to-fixed multiplication.
  • Dynamic-to-dynamic multiplication.
  • Fixed-to-dynamic multiplication.
  • Dynamic-to-fixed multiplication.

Overview

Matrix multiplication combines two matrices:

A(M×N) · B(N×P) = C(M×P)

The number of columns in the left matrix must match the number of rows in the right matrix.

Fixed Matrices

Fixed-size multiplication is resolved entirely at compile time.

FixedMatrix<float, 2, 3> A;
FixedMatrix<float, 3, 2> B;
FixedMatrix<float, 2, 2> C;
Multiply(A, B, C);

Matrix dimensions are validated by the compiler through template parameters.

Dynamic Matrices

Dynamic matrices are checked at runtime.

DynamicMatrix<float> A;
DynamicMatrix<float> B;
DynamicMatrix<float> C;
if(Multiply(A, B, C))
{
// Success
}

The result matrix is automatically resized when required.

Mixed Matrices

Mixed multiplication between fixed and dynamic matrices is also supported.

Fixed × Dynamic:

FixedMatrix<float, 3, 3> A;
DynamicMatrix<float> B;
DynamicMatrix<float> C;
Multiply(A, B, C);

Dynamic × Fixed:

DynamicMatrix<float> A;
FixedMatrix<float, 3, 3> B;
DynamicMatrix<float> C;
Multiply(A, B, C);

Computational Complexity

Matrix multiplication is implemented using the classical triple-nested-loop algorithm:

for(i)
for(j)
for(k)

Time complexity:

O(MNP)

Memory complexity:

O(1)

excluding storage required for the result matrix.

Applications

Typical applications include:

  • Coordinate transformations.
  • Robotics kinematics.
  • State-space control systems.
  • DSP processing.
  • Machine learning.
  • Numerical linear algebra.
