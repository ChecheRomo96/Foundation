Detailed Description

Matrix arithmetic algorithms.

This module provides algorithms operating on matrix types such as Fixed and Dynamic.

Currently supported operations include:

  • Matrix multiplication.
  • Fixed-to-fixed multiplication.
  • Dynamic-to-dynamic multiplication.
  • Fixed-to-dynamic multiplication.
  • Dynamic-to-fixed multiplication.

Overview

Matrix multiplication combines two matrices:

A(M×N) · B(N×P) = C(M×P)

The number of columns in the left matrix must match the number of rows in the right matrix.

Fixed Matrices

Fixed-size multiplication is resolved entirely at compile time.

Foundation::Math::Matrix::Fixed<float, 2, 3> A;
Foundation::Math::Matrix::Fixed<float, 3, 2> B;
Foundation::Math::Matrix::Fixed<float, 2, 2> C;
Foundation::Math::Matrix::Multiply(A, B, C);

Dynamic Matrices

Dynamic matrices are checked at runtime.

Foundation::Math::Matrix::Dynamic<float> A;
Foundation::Math::Matrix::Dynamic<float> B;
Foundation::Math::Matrix::Dynamic<float> C;
if (Foundation::Math::Matrix::Multiply(A, B, C)) {
// Success
}
Foundation::Math::Matrix::Dynamic
Matrix whose dimensions and storage are selected at runtime.

The result matrix is automatically resized when required. Compatible attached storage is reused, so an embedded application can provide the output buffer without allocating from the heap.

Multiply() returns false without modifying the output when an input is invalid, dimensions are incompatible, allocation fails, or output storage overlaps either input. Pass a distinct result matrix; this includes matrices attached to different regions of the same overlapping buffer.

Mixed Matrices

Mixed multiplication between fixed and dynamic matrices is also supported.

Fixed × Dynamic:

Foundation::Math::Matrix::Fixed<float, 3, 3> A;
Foundation::Math::Matrix::Dynamic<float> B;
Foundation::Math::Matrix::Dynamic<float> C;
Foundation::Math::Matrix::Multiply(A, B, C);

Dynamic × Fixed:

Foundation::Math::Matrix::Dynamic<float> A;
Foundation::Math::Matrix::Fixed<float, 3, 3> B;
Foundation::Math::Matrix::Dynamic<float> C;
Foundation::Math::Matrix::Multiply(A, B, C);

Computational Complexity

Matrix multiplication is implemented using the classical triple-nested-loop algorithm:

for(i)
for(j)
for(k)

Time complexity:

O(MNP)

Memory complexity:

O(1)

excluding storage required for the result matrix.

Applications

Typical applications include:

  • Coordinate transformations.
  • Robotics kinematics.
  • State-space control systems.
  • DSP processing.
  • Machine learning.
  • Numerical linear algebra.
