MSVC and Clang builds for Windows.

Supported Windows Toolchains

Windows precompiled libraries must be separated by toolchain.

Supported target presets:

windows_msvc_x64
windows_clang_x64

windows_msvc_x64 selects the Visual Studio 18 2026 multi-configuration generator and x64 architecture. windows_clang_x64 selects clang/clang++ with Ninja Multi-Config and validates that the host processor is x86-64. Their archives are separate compatibility products even when both use .lib.

Optional future presets:

windows_mingw_x64

MSVC

MSVC uses a multi-configuration generator.

CMAKE_BUILD_TYPE is ignored by Visual Studio generators. Always pass the configuration during build and install.

Run from Visual Studio Developer PowerShell so MSVC, the Windows SDK, and environment variables refer to the same installation.

Get-Command cmake
Get-Command cl
./scripts/configure.ps1 windows_msvc_x64 -Fresh
./scripts/build.ps1 windows_msvc_x64 `
-Configuration Debug -Target Foundation
./scripts/build.ps1 windows_msvc_x64 `
-Configuration Release -Target Foundation

For Clang, verify clang++ and ninja, then replace the preset name with windows_clang_x64 in the same workflow.

Export

Recommended:

./scripts/export.ps1 windows_msvc_x64 -Fresh

The export command builds and installs a Release-only package. Expect Foundation.lib, public headers, build metadata, and Release imported-target files below dist/windows_msvc_x64. Foundation_d.lib remains available only in the source build tree. Add -ExamplesOn only when the package should include Release API examples. The package then includes one FoundationExamples.cmd menu launcher that asks after every selected example whether to return to the menu or exit. See Manual Workflow for the complete local sequence and the distinction between incremental and clean configuration.

Test Status

Native Windows runs the registered CTest suite. Execute all discovered GoogleTest cases in both Debug and Release for windows_msvc_x64 and windows_clang_x64; a zero-test result is not release evidence. Use a fresh export afterward so unrelated cached feature overrides do not leak into the release package.

Validation

Inspect MSVC output with dumpbin /headers and Clang output with llvm-readobj where available. Compile a separate x64 consumer using find_package(Foundation CONFIG REQUIRED) in Release and verify it selects Foundation.lib. Build Foundation from source for Debug consumers. The complete command checklist is in Validation.
