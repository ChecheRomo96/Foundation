MSVC

MSVC uses a multi-configuration generator.

CMAKE_BUILD_TYPE is ignored by Visual Studio generators. Always pass the configuration during build and install.

cmake --preset windows_msvc_x64_release
cmake --build --preset windows_msvc_x64_release --config Release
cmake --install build/windows_msvc_x64_release --config Release --prefix dist/windows_msvc_x64_release
