Evidence Types

Mark Meaning
BEHAVIOR A GoogleTest case exercises runtime or constant-evaluated behavior.
CONFORMANCE The result is compared with the C++17 standard contract, including the local fallback implementation.
COMPILE A dedicated translation unit or static_assert verifies the public shape.
CONFIGURATION CMake accepts or rejects an option combination as intended.
CONSUMER A project outside the Foundation build finds, links, and runs the installed package.
TARGET Cross-compilation proves the source and archive for a target ABI; it does not prove runtime behavior.
GAP No adequate direct evidence exists yet. The owning backlog item is named in the table.

CTest is the runner used by the repository scripts. GoogleTest remains the unit-test framework. A passing umbrella-header test proves that the symbol is reachable through that umbrella; it does not replace member-level behavior.

Target-only Evidence

Native tests cannot execute an AVR or Cortex-M binary. Embedded CI therefore has a narrower but truthful contract: compile Debug and Release with the target toolchain, export the Release package, and inspect an object inside libFoundation.a with the matching binutils. Hardware or emulator execution remains part of VAL-007, VAL-008, and VAL-009.
