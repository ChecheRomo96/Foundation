Detailed Description

template<typename TickType = Foundation::Time::Tick32>
class Foundation::Scheduling::BasicTaskScheduler< TickType >

Fixed-capacity cooperative scheduler driven by a Clock.

Template Parameters
TickTypeTick specialization shared by its Clock and Tasks.

Stores non-owning BasicTask pointers in caller-provided storage. Update() executes due tasks synchronously in registration order.

Parameters
tasksArray capable of storing capacity Task pointers.
capacityMaximum number of registered tasks.
clockNon-owning clock used by Update(); may be null.
Note
A null tasks pointer with zero capacity is valid. A null pointer with non-zero capacity creates an invalid but safe scheduler for which AddTask() returns false and Update() is a no-op.
Warning
The storage, clock, and registered tasks must outlive their use by the scheduler.
