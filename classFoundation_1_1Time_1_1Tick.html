Detailed Description

template<typename T = uint32_t>
class Foundation::Time::Tick< T >

Strongly typed wrapping value for an unsigned hardware counter.

Template Parameters
TUnsigned integer representation; defaults to uint32_t and rejects bool.

Every bit pattern of the representation is a valid raw counter value. Elapsed-time validity and modular ordering belong to BasicDuration and BasicTimePoint rather than to the raw Tick.
