Build Guide
Collaboration diagram for Workflow:

Foundation separates temporary build files from distributable artifacts.

Directory Meaning

build/

Temporary CMake build workspace. This directory is not distributed.

dist/

Installed/exported Foundation distribution. This directory contains headers, libraries, and CMake package files when available.

Development Workflow

During development, build inside the build directory:

cmake --preset windows_msvc_x64_debug
cmake --build --preset windows_msvc_x64_debug --config Debug

The output remains inside:

build/windows_msvc_x64_debug/

Release Check

Before exporting, verify the release preset:

cmake --preset windows_msvc_x64_release
cmake --build --preset windows_msvc_x64_release --config Release

Export Workflow

To generate a distributable package:

./scripts/export.ps1 windows_msvc_x64_release Release

or:

./scripts/export.sh psoc5lp_armgcc_cortex_m3_soft_release

This creates:

dist/<preset-name>/

Clean Workflow

To clean one preset:

./scripts/clean.ps1 windows_msvc_x64_release

To clean all build and dist outputs:

./scripts/clean.ps1
