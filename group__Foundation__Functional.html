Detailed Description

Allocation-free callable utilities for embedded and desktop code.

Functional currently exposes one public component: Callback. This is the complete implemented v1 surface of the module, not a missing-documentation placeholder. Additional functional utilities should appear here only after they have an implemented, tested, and reviewed public contract.

Basic Usage

#include <Foundation_Functional.h>
int Add(int first, int second) {

}

callback.Bind(Add);
const int result = callback.Invoke(2, 3);

Callback stores either a free/static function pointer or a non-owning object pointer plus a member-function invoker. It performs no heap allocation and offers IsBound() and Unbind() for explicit state management.

Current Contract

  • Bound objects are not owned; they must outlive the binding and every call.
  • Non-const and const member functions are supported. Const functions may be bound to const objects.
  • A callback without arguments uses an empty pack: Callback<R> or Callback<void>. void is not an argument placeholder.
  • If FOUNDATION_EXCEPTIONS is enabled, invoking an empty callback throws std::runtime_error. Otherwise a non-void callback returns R{} and a void callback performs no operation.
  • Callback invocation is synchronous and is not internally synchronized.
