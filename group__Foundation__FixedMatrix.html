Fixed-size matrix container.

Fixed-size matrix container.

The FixedMatrix class provides a statically allocated matrix whose dimensions are known at compile time.

Unlike dynamically allocated matrices, all storage is embedded directly within the object:

FixedMatrix<float, 3, 3> matrix;

This design avoids heap allocation and provides deterministic memory usage, making it suitable for embedded systems and real-time applications.

Features

  • Compile-time dimensions.
  • No dynamic memory allocation.
  • Direct element access.
  • Matrix addition and subtraction.
  • Scalar multiplication and division.
  • Matrix transposition.
  • Compatible with generic numeric types.

Memory Layout

Elements are stored internally as:

T data[Rows][Cols];

in row-major order.

Example:

[ a00 a01 a02 ]
[ a10 a11 a12 ]
[ a20 a21 a22 ]

Construction

Default construction:

FixedMatrix<float, 2, 2> A;

Fill construction:

FixedMatrix<float, 2, 2> A(1.0f);

Array initialization:

float values[2][2] =
{
{1.0f, 2.0f},
{3.0f, 4.0f}
};
FixedMatrix<float, 2, 2> A(values);

Element Access

Access using At():

float value = matrix.At(1, 2);

Access using operator[]:

matrix[1][2] = 42.0f;

Arithmetic Operations

Matrix addition:

auto C = A + B;

Matrix subtraction:

auto C = A - B;

Scalar multiplication:

auto B = A * 2.0f;
auto C = 2.0f * A;

Scalar division:

auto B = A / 2.0f;

Transpose

The transpose operation exchanges rows and columns:

::contentReference[oaicite:0]{index=0}

FixedMatrix<float, 2, 3> A;
auto AT = A.Transposed();
// Result type:
// FixedMatrix<float, 3, 2>

Applications

Typical applications include:

  • Coordinate transformations.
  • DSP processing.
  • Control systems.
  • State-space models.
  • Robotics kinematics.
  • Embedded numerical algorithms.
