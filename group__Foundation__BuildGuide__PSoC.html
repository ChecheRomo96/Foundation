Why not every chip

Foundation should not initially generate one distribution per PSoC chip.

The minimum useful split is:

  • toolchain,
  • CPU core,
  • ABI/FPU mode,
  • configuration.

Since Foundation is mostly portable C++ and does not depend on chip registers, a PSoC 5LP Cortex-M3 soft-float build can cover the typical CY8CKIT-059 use case. The preset produces a generic Cortex-M3 soft-float static archive. It does not provide PSoC Creator startup code, generated components, linker script, device headers, or project metadata.

The consuming PSoC project must use a compatible Arm GNU compiler/runtime and the same Thumb, Cortex-M3, and soft-float ABI. Compiler compatibility must be validated with the exact PSoC Creator/toolchain version used by the product.

Export

Example:

./scripts/export.ps1 psoc5lp_armgcc_cortex_m3_soft

or:

./scripts/export.sh psoc5lp_armgcc_cortex_m3_soft

Output:

dist/psoc5lp_armgcc_cortex_m3_soft/

Inspect the Release archive with arm-none-eabi-objdump -f and link it into a minimal PSoC firmware before publishing. Do not use host CTest as proof of embedded execution.
