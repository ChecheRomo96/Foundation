# Period

## Scenario

A period and its reciprocal frequency retain units during conversion and mutation.

## Interfaces

`Period`, `Frequency`, `Ratio`, `Set`, and `IsValid`.

## Run and inspect

Open `Period.ino` in Arduino IDE and set the serial monitor to **115200 baud**. The sketch prints the source expression, the concrete input, and an interpreted result; it is a demonstration rather than a PASS/FAIL test.

## Extend it

Use a zero numerator/denominator case to see explicit invalid-state handling.
