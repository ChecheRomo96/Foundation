# Frequency

## Scenario

Frequency and its reciprocal period retain units during conversion and mutation.

## Interfaces

`Frequency`, `Period`, `Ratio`, `Set`, and `IsValid`.

## Run and inspect

Open `Frequency.ino` in Arduino IDE and set the serial monitor to **115200 baud**. The sketch prints the source expression, the concrete input, and an interpreted result; it is a demonstration rather than a PASS/FAIL test.

## Extend it

Use a zero numerator/denominator case to see explicit invalid-state handling.
