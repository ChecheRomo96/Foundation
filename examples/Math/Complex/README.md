# Complex

## Scenario

Two phasor-like complex values are combined and inspected without discarding their components.

## Interfaces

`Complex<T>`, addition, multiplication, `Conjugate`, and `MagnitudeSquared`.

## Run and inspect

Open `Complex.ino` in Arduino IDE and set the serial monitor to **115200 baud**. The sketch prints the source expression, the concrete input, and an interpreted result; it is a demonstration rather than a PASS/FAIL test.

## Extend it

Replace either operand and relate the real/imaginary output to the operation.
