# Arithmetic

## Scenario

A control calculation finds a common sample interval and converts a half/quarter turn.

## Interfaces

`GCD`, `Pi`, `DegToRad`, and `RadToDeg` make integer and angular units explicit.

## Run and inspect

Open `Arithmetic.ino` in Arduino IDE and set the serial monitor to **115200 baud**. The sketch prints the source expression, the concrete input, and an interpreted result; it is a demonstration rather than a PASS/FAIL test.

## Extend it

Change the angles or integer pair and inspect the corresponding units in Serial.
