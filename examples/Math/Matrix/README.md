# Matrix

## Scenario

Static and dynamic matrices show element access, transpose, ownership, and multiplication.

## Interfaces

`Matrix<T>`, element access, `Transpose`, and multiplication.

## Run and inspect

Open `Matrix.ino` in Arduino IDE and set the serial monitor to **115200 baud**. The sketch prints the source expression, the concrete input, and an interpreted result; it is a demonstration rather than a PASS/FAIL test.

## Extend it

Alter dimensions or values, then follow the printed rows to verify the order.
