Foundation Documentation

Documentation for the Foundation framework.

Foundation is a modular C++ framework for embedded and desktop software development.

It provides reusable, lightweight components intended to serve as a common base layer for embedded applications, desktop tools, and higher-level frameworks.

Overview

Foundation is organized into independent modules. Each module focuses on a specific domain and may be enabled or disabled through the build system.

Getting Started

For small applications, examples, and Arduino-style projects, include the main header:

#include <Foundation.h>

For larger projects or library code, prefer selective module headers:

#include <Foundation_Math.h>
#include <Foundation_Time.h>

Design Goals

Foundation is designed with the following goals:

  • Embedded-first architecture.
  • Desktop compatibility.
  • Modular feature selection.
  • Stable top-level public headers.
  • Minimal runtime overhead.
  • Minimal dependency on the C++ standard library.
  • Clear separation between public API and internal implementation.

Target Platforms and Support Status

Foundation provides build or integration paths for:

  • Windows
  • Linux
  • macOS
  • Arduino-style environments
  • AVR-GCC / ATmega328P
  • PSoC Creator projects
  • STM32 projects
  • Other C++17-capable embedded targets

Availability does not imply completed support validation. Consult Support Matrix for the evidence-backed level of each target and Known Limitations before selecting Foundation for a release.

Requirements

Foundation 1.2.0 requires C++17 or newer in CMake package, direct-source, Arduino-style, desktop, and embedded builds. Requiring the C++17 language does not mean every target must provide the complete C++ standard library.
