Detailed Description

template<typename TickType = Tick32>
class Foundation::Time::BasicTimePoint< TickType >

Tick value associated with the identity of one Clock.

Template Parameters
TickTypeTick specialization shared with the Clock.

The Clock pointer is non-owning and is used for compatibility checks. Valid points can only be created by their Clock through Now() or At(), and that Clock must outlive every operation that inspects the point.
