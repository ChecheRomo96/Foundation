Detailed Description

Fixed-size matrix container.

The Fixed class provides a statically allocated matrix whose dimensions are known at compile time.

Unlike dynamically allocated matrices, all storage is embedded directly within the object:

Foundation::Math::Matrix::Fixed<float, 3, 3> matrix;
Foundation::Math::Matrix::Fixed
Represents a statically allocated matrix with fixed dimensions.
Definition Fixed.h:22

This design avoids heap allocation and provides deterministic memory usage, making it suitable for embedded systems and real-time applications.

Features

  • Compile-time dimensions.
  • No dynamic memory allocation.
  • Direct element access.
  • Matrix addition and subtraction.
  • Scalar multiplication and division.
  • Matrix transposition.
  • Compatible with generic numeric types.

Memory Layout

Elements are stored internally as:

T data[Rows][Cols];

in row-major order.

Example:

[ a00 a01 a02 ]
[ a10 a11 a12 ]
[ a20 a21 a22 ]

Construction

Default construction:

Foundation::Math::Matrix::Fixed<float, 2, 2> A;

Fill construction:

Foundation::Math::Matrix::Fixed<float, 2, 2> A(1.0f);

Array initialization:

float values[2][2] = {
{1.0f, 2.0f},
{3.0f, 4.0f}
};
Foundation::Math::Matrix::Fixed<float, 2, 2> A(values);

Transpose

The transpose operation exchanges rows and columns:

Foundation::Math::Matrix::Fixed<float, 2, 3> A;
auto AT = A.Transposed();
// Result type:
// Fixed<float, 3, 2>

Applications

Typical applications include:

  • Coordinate transformations.
  • DSP processing.
  • Control systems.
  • State-space models.
  • Robotics kinematics.
  • Embedded numerical algorithms.
