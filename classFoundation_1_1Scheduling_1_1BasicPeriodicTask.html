Detailed Description

template<typename TickType = Foundation::Time::Tick32>
class Foundation::Scheduling::BasicPeriodicTask< TickType >

Task that runs immediately and then at a fixed tick interval.

Template Parameters
TickTypeTick specialization shared with its scheduler.

The first ShouldRun() returns true. After Run(), the next due time is measured from the TimePoint passed to that invocation.

Parameters
callbackFunction invoked when the task runs; may be null.
contextNon-owning pointer forwarded unchanged to callback.
periodMinimum number of ticks between runs after the first.
Note
A null context is allowed and is forwarded to a non-null callback. A null callback makes Run() update timing without invoking user code.
Warning
A non-null context must outlive the task and all invocations.
