Detailed Description

Cartesian complex numbers for any arithmetic type.

Complex<T> stores public real and imag parts and provides the usual arithmetic, comparison, conjugation, and squared-magnitude operations. The module is enabled by FOUNDATION_MATH_COMPLEX and does not depend on the C++ standard library or on floating-point support, so integer specializations remain usable on targets without an FPU.

Foundation::Math::Complex<float> z(3.0f, 4.0f);
Foundation::Math::Complex<float> product = z * z.Conjugate();
// product.real == 25.0f, product.imag == 0.0f
