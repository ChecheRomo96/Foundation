Detailed Description

template<typename... Args>
class Foundation::Functional::Callback< void, Args... >

Allocation-free callback with no return value.

An empty Args... pack represents a callback with neither a return value nor arguments: Callback<void>.

Template Parameters
ArgsCallback argument types; the pack may be empty.
